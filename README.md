# 🌱 Crop Disease Prediction System

## 📌 Overview
The Crop Disease Prediction System is a deep learning-based web application that detects crop diseases from uploaded leaf images. It uses a Convolutional Neural Network (CNN) model to provide accurate disease predictions along with treatment recommendations, helping improve agricultural productivity and support sustainable farming.

---

## ✨ Features
- Upload crop leaf images for disease prediction
- Real-time image classification using a CNN model
- Displays disease prediction with treatment recommendations
- User-friendly web interface
- Optimized model for improved accuracy and performance

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/DharshikaSree/Crop_Disease_Prediction.git
```

2. Navigate to the project folder

```bash
cd Crop_Disease_Prediction
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the Flask application

```bash
python app.py
```

5. Open your browser and visit:

```
http://127.0.0.1:5000
```

---

## 💡 How It Works

1. Upload a leaf image.
2. The CNN model processes the image.
3. The system predicts the disease.
4. Treatment recommendations are displayed.
